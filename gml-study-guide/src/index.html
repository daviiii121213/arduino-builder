Função reutilizável Script: scr_util
            /// @function aproximar(valor, alvo, passo)
            /// @description Leva "valor" até "alvo" sem ultrapassar.
            function aproximar(_valor, _alvo, _passo) {
                if (_valor < _alvo) return min(_valor + _passo, _alvo);
                return max(_valor - _passo, _alvo);
            }
            hsp = aproximar(hsp, 0, 0.3);    // em qualquer objeto: freia
DicaPrefixe parâmetros com _ para não confundir com variáveis da instância. Sem return, a função devolve undefined.

06Sistema de plataforma

            // Create
            hsp = 0;   vsp = 0;   grv = 0.4;
            vel = 3;   forca_pulo = -7;
            // Step — horizontal + gravidade
            hsp = (keyboard_check(vk_right)
                - keyboard_check(vk_left)) * vel;
            vsp = min(vsp + grv, 10);      // queda máx.
            var chao = place_meeting(x, y + 1, obj_bloco);
            if (chao && keyboard_check_pressed(vk_space))
                vsp = forca_pulo;           // pulo
            if (vsp < 0 && !keyboard_check(vk_space))
                vsp = max(vsp, forca_pulo / 2); // curto
            // parede: encosta 1 px por vez e para
            if (place_meeting(x + hsp, y, obj_bloco)) {
                var sx = sign(hsp);
                while (!place_meeting(x + sx, y, obj_bloco))
                    x += sx;
                hsp = 0;
            }
            x += hsp;
            if (place_meeting(x, y + vsp, obj_bloco)) { // y
                var sy = sign(vsp);
                while (!place_meeting(x, y + sy, obj_bloco))
                    y += sy;
                vsp = 0;
            }
            y += vsp;
DefiniçãoDireto: você soma a x/y (controle total, como acima). Por velocidade: define speed/hspeed e o GameMaker move sozinho — ideal para projéteis. Não misture.

              }
              break;
          case ESTADO.JUMP:
              hsp = h * 3;
              if (vsp >= 0) estado = ESTADO.FALL;
              break;
          case ESTADO.FALL:
              hsp = h * 3;
              if (chao) estado = ESTADO.IDLE;   break;
        
              case ESTADO.ATTACK:
                  hsp = 0;
                  if (image_index >= image_number - 1)
                      estado = ESTADO.IDLE;
                  break;
              case ESTADO.HURT:  // t_dano = 20 ao ser atingido
                  t_dano -= 1;
                  if (t_dano <= 0) estado = ESTADO.IDLE;
                  if (hp <= 0)     estado = ESTADO.DEAD;
                  break;
              case ESTADO.DEAD:  hsp = 0;  break;
          }
          sprite_index = sprites[estado];  // enum = índice
          // + gravidade e colisão (Folha 2 §06)

13Checklist de desempenho

  • Destrua o que sai da tela; evite criar instâncias em massa.
  • Sem laços aninhados sobre todas as instâncias no Step.
  • Colisão só quando precisa; máscaras simples.
  • Todo ds_*_create tem seu destroy.
  • Surfaces e partículas: crie 1×, reutilize, libere.
