05FunçõesSCRIPTS · MÉTODOS

ConceitoO que fazExemplo GML
functionDeclara; num Script é global.function dobro(_n) { return _n * 2; }
argumentosParâmetros, com valor padrão.function curar(_q = 1) { hp += _q; }
returnDevolve valor e encerra.return clamp(_v, 0, 1);
varLocal à chamada da função.var soma = 0;
métodoFunção guardada em variável.atacar = function() { hp--; };
staticMantém valor entre chamadas.static usos = 0; usos++;
Função reutilizável Script: scr_util
            /// @function aproximar(valor, alvo, passo)
            /// @description Leva "valor" até "alvo" sem ultrapassar.
            function aproximar(_valor, _alvo, _passo) {
                if (_valor < _alvo) return min(_valor + _passo, _alvo);
                return max(_valor - _passo, _alvo);
            }
            hsp = aproximar(hsp, 0, 0.3);    // em qualquer objeto: freia
DicaPrefixe parâmetros com _ para não confundir com variáveis da instância. Sem return, a função devolve undefined.
