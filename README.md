# Doce Encanto — Sistema para Confeitaria

Aplicação web completa para uma confeitaria brasileira, com Painel do Cliente e Painel do Vendedor.
O projeto fica em [`confeitaria/`](confeitaria).

```bash
cd confeitaria
npm install
npm run dev   # http://localhost:5173
```

Acesso do vendedor: botão discreto **Vendedor** na tela inicial, código **123**.
Documentação completa em [`confeitaria/README.md`](confeitaria/README.md).
